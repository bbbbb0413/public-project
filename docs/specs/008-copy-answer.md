## 배경 / 문제
`public-front/src/components/AiService.tsx:439-469` 에서 AI가 생성한 답변은 `ReactMarkdown` 을 통해 렌더링된다. AI 응답에는 긴 설명문, 코드 블록, 마크다운 목록 등이 포함되지만 이를 외부(메신저, 문서 도구, 코드 에디터 등)로 복사할 수 있는 기능이 없다.
현재 사용자가 AI 답변을 복사하려면 마우스 드래그로 텍스트 영역을 직접 선택해야 한다. 이 과정에서 마크다운 서식이 깨지거나, 답변 하단에 함께 렌더링되는 신뢰도 배지(`confidence-badge`) 및 확인하지 못한 항목(`missing-info`) 같은 메타 정보 UI 텍스트까지 함께 선택되는 불편이 있다.
AI 답변 원문 텍스트를 원클릭으로 클립보드에 복사할 수 있는 편의 기능이 필요하다.

## 요구사항
- [ ] 완료된 AI 메시지 버블에 "복사" 버튼을 추가한다
- [ ] 복사 버튼 클릭 시 AI 답변 원문 텍스트(`msg.text`)를 `navigator.clipboard.writeText` 로 클립보드에 복사한다
- [ ] 복사 성공 시 해당 버튼 텍스트가 2초 동안 "복사됨" 으로 변경된 후 다시 "복사" 로 복귀한다
- [ ] 여러 AI 메시지가 존재할 때 각 메시지의 복사 상태("복사됨" 피드백)는 독립적으로 동작한다
- [ ] 클립보드 복사 API 호출 실패 시 에러 배너에 "답변 복사에 실패했습니다." 에러 메시지를 노출한다
- [ ] 사용자(user) 메시지 버블에는 복사 버튼을 표시하지 않는다
- [ ] 답변이 스트리밍 중인 임시 버블(`isStreaming`)에는 복사 버튼을 표시하지 않는다
- [ ] 키보드 접근성을 위해 복사 버튼은 표준 `button` 요소를 사용하고 적절한 `aria-label` 을 제공한다
- [ ] 위 동작을 검증하는 컴포넌트 단위 테스트를 작성한다

## 비요구사항 (Out of scope)
- 답변 내부의 개별 코드 블록 단위 복사 버튼 (답변 전체 텍스트 복사만 다룬다)
- 마크다운을 서식 있는 HTML(Rich Text)로 변환해 복사하는 기능 (순수 마크다운 문자열 복사로 한정)
- 사용자 질문 텍스트 복사 기능
- 복사 성공 이력이나 횟수를 서버/세션에 기록하는 처리

## 프론트엔드
`public-front/src/components/AiService.tsx`
- AI 메시지 렌더링 블록(`msg.sender === 'ai'`) 내부에 복사 버튼을 배치한다.
- 클릭 시 `navigator.clipboard.writeText(msg.text)` 를 호출한다.
- 복사 완료 피드백을 위해 복사된 메시지의 고유 식별자 또는 인덱스를 상태로 관리하고 2초 후 타이머로 초기화한다.
- 복사 실패 시 `setErrorMsg('답변 복사에 실패했습니다.')` 를 호출하여 사용자에게 오류를 안내한다.

`public-front/src/components/AiService.css`
- 복사 버튼 배치 및 시각 스타일(호버, 포커스 링, 상태 전환)을 정의한다.

## 수용 기준 (Acceptance Criteria)
- Given 완료된 AI 답변이 화면에 표시된 경우 When 사용자가 "복사" 버튼을 클릭하면 Then 클립보드에 해당 AI 답변의 마크다운 원문 텍스트가 복사되고 버튼 텍스트가 2초간 "복사됨" 으로 변경된다
- Given 2초가 지난 경우 When "복사됨" 상태였던 버튼을 확인하면 Then 버튼 텍스트가 다시 "복사" 로 복구된다
- Given 대화창에 복수의 AI 답변이 존재하는 경우 When 특정 AI 답변의 복사 버튼을 클릭하면 Then 클릭된 메시지의 버튼만 "복사됨" 으로 변경되고 다른 메시지의 복사 버튼 상태에는 영향을 주지 않는다
- Given AI 답변이 실시간으로 스트리밍 중인 경우 When 화면을 확인하면 Then 스트리밍 중인 메시지 버블에는 복사 버튼이 노출되지 않는다
- Given 사용자가 입력한 메시지 버블인 경우 When 화면을 확인하면 Then 복사 버튼이 노출되지 않는다
- Given `navigator.clipboard.writeText` 호출이 실패(reject)한 경우 When 사용자가 복사 버튼을 클릭하면 Then 버튼 텍스트가 변경되지 않고 상단 에러 배너에 "답변 복사에 실패했습니다." 가 표시된다
- Given 복사 버튼에 키보드 포커스가 있는 경우 When Enter 키를 누르면 Then 마우스 클릭과 동일하게 클립보드 복사가 실행된다
