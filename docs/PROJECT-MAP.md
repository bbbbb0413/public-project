# 코드 지도
## 저장소 구조 규약
- `public-front` — React 18 + Vite + TypeScript 기반 SPA. `src/api/`가 게이트웨이 REST/SSE 통신을 전담하고, `src/components/`가 UI 컴포넌트와 비즈니스 인터랙션을 처리한다. WebSocket(Socket.IO) 실시간 채팅은 `src/hooks/useChatSocket.ts` 및 FlatBuffers 직렬화를 사용한다.
- `public-server` — NestJS 모노레포 구조 (`apps/*`, `libs/*`). 외부 HTTP/SSE/WebSocket 진입점은 `apps/gateway`가 단독으로 처리하며, 내부 마이크로서비스(`identity`, `payment`, `chat-service`, `admin-server`)와는 gRPC(`*.grpc-controller.ts`)로 통신한다. 공통 인증·보안·DB 유틸리티는 `libs/*`에 모여 있다. 레거시 AI 모듈인 `apps/ai-service`는 Python 서비스로 이관되었으며 현재 게이트웨이 프록시로 대체되었다.
- `public-python-server` — FastAPI 기반 Clean Architecture/DDD 구조. 도메인 모듈별로 `router.py`(HTTP 진입점), `service.py`(응용 로직), `repository.py`(영속화/DB), `schemas.py`(데이터 모델)로 구성된다. Kafka 이벤트 수신기는 각 도메인의 `infrastructure/messaging/*_consumer.py`에 위치한다. `observability/` 내부의 빈 계층 디렉토리(`application/`, `domain/` 등)는 구조 단순화 과정에서 남은 흔적이다.
