# 코드 지도
## 저장소 구조 규약
- `front` (`public-front`) — React 19 + Vite + TypeScript 기반 SPA. `src/api/`에 게이트웨이 REST·SSE 통신 모듈을 두고, `src/components/`(일반 화면 및 `ai/`, `admin/` 하위 도메인)에 UI 컴포넌트를 배치한다. 전역 인증 상태는 `src/context/`에서 관리하며, 실시간 채팅 WebSocket 연결은 `src/hooks/useChatSocket.ts`와 `src/flatbuffers/`(FlatBuffers 직렬화)가 담당한다.
- `python-server` (`public-python-server`) — FastAPI 기반 AI 마이크로서비스(`src/ai_service/`). 진입점 `main.py` 아래 도메인별 디렉토리(`rag/`, `knowledge/`, `llm_gateway/`, `prompt/`, `feedback/`, `observability/`)마다 `router.py`(HTTP 입구), `service.py` 또는 `application/*_use_case.py`(로직), `repository.py`(MongoDB·Qdrant·Redis 저장), `schemas.py`(도메인 모델 및 계약), `dependencies.py`(DI)를 둔다. Kafka 이벤트 소비자는 `infrastructure/messaging/*_consumer.py`에 모이며, 각 도메인 하위 `domain/*`, `presentation/`, `infrastructure/persistence/` 등의 빈 디렉토리는 계층 단순화 리팩터링 과정에서 남은 흔적이다.
- `server` (`public-server`) — NestJS 모노레포(`apps/*`, `libs/*`). 외부 HTTP·SSE·WebSocket 요청은 `apps/gateway`가 단독 진입점으로 받아 내부 마이크로서비스(`apps/identity`, `apps/payment`, `apps/chat-service`, `apps/admin-server`)에 gRPC(`*.grpc-controller.ts`)로 위임하거나, `apps/gateway/src/ai/proxy/*-proxy.controller.ts`를 통해 `public-python-server`로 HTTP 프록시한다. 공통 인증(`libs/auth`), gRPC·FlatBuffers 계약(`libs/rpc`), DB·로깅·예외 처리(`libs/common`)는 `libs/`에 모이며, `apps/ai-service`는 Python 서버로 이관되기 전의 레거시 NestJS AI 애플리케이션이다.

## 아쉬운 곳
- **에이전틱 RAG(복합 질문) 경로에서 다회차 세션 대화 이력(`sessionId`) 복원과 후속 질문 재작성(`ConversationalQueryRewriter`)이 빠져 있다** — `public-front/src/components/AiService.tsx:610` (`handleSendQuestion`)은 `sessionId`가 있으면 서버가 세션에서 이력을 읽도록 `prevChatLog`를 빈 배열(`[]`)로 비워 전송한다(`public-front/src/api/ai.ts:476-484`). 단순 질문 경로인 `public-python-server/src/ai_service/rag/application/ask_use_case.py:76-88` (`AskUseCase.execute`)는 `command.session_id`로 세션 이력(`session.get_history()`)을 복원하고 `ConversationalQueryRewriter.rewrite`로 대명사·생략 표현을 보완하지만, 복합 질문 경로인 `public-python-server/src/ai_service/rag/infrastructure/messaging/ask_requested_consumer.py:104, 130-141` (`AskRequestedConsumer._process`)은 이미 조회한 `session`의 이력을 넘기지 않고 `message.conversation_history`(`None`)만 전달하며, `public-python-server/src/ai_service/rag/application/agentic_ask_use_case.py:57-111` (`AgenticAskUseCase.execute`)에도 세션 이력 복원과 질문 재작성 단계가 없어 기존 세션의 2번째 질문부터 복합 질문이 들어오면 이전 대화 맥락이 통째로 유실된다.
- **프론트엔드·게이트웨이의 대화 보관함(북마크) 기능 및 세션 검색 파라미터(`q`)가 Python 백엔드에 연결되어 있지 않다** — `public-front/src/components/AiService.tsx:96-99, 155-226, 959-970, 1039-1046, 1060-1095`와 `public-front/src/api/ai.ts:320-358` (`getSessions`, `toggleSessionBookmark`, `getBookmarks`, `createBookmark`, `deleteBookmark`), 게이트웨이 `public-server/apps/gateway/src/ai/proxy/rag-session-proxy.controller.ts:35-56, 70-109, 124-169` (`RagSessionProxyController`)에는 세션 북마크 토글(`PATCH /ai/rag/sessions/:sessionId/bookmark`), 답변 보관함 조회·생성·삭제(`/ai/rag/bookmarks`)가 구현되어 있으나, `public-python-server/src/ai_service/rag/router.py:16-57` 및 `public-python-server/src/ai_service/rag/schemas.py:372-386` (`SessionOut`)에는 북마크 라우트와 `SessionOut.isBookmarked`·`snippet` 필드가 아예 없다. 또한 세션 검색 시 `public-front/src/api/ai.ts:324` (`getSessions`)와 `rag-session-proxy.controller.ts:44-50` (`RagSessionProxyController.getSessions`)은 쿼리 파라미터 `q`를 전달하지만, `public-python-server/src/ai_service/rag/router.py:17-25` (`get_sessions`)는 `keyword` 파라미터만 받고 `q`를 무시해 사이드바 대화 검색이 필터링되지 않는다.
- **관리자 전역 프롬프트 프록시(`PromptProxyController`)가 관리자 세션을 `userId`로 주입해 전역 프롬프트 생성·활성화가 작동하지 않으며, 개인 프롬프트 슬롯 목록에 전역 프롬프트가 섞여 내려온다** — `public-python-server/src/ai_service/prompt/repository.py:46, 57, 72, 77-81` (`PromptTemplateRepository`)은 `userId` 필드가 없는 문서를 관리자 전역 프롬프트로 취급한다. 그러나 `public-server/apps/gateway/src/ai/proxy/prompt-proxy.controller.ts:35-46, 52-60, 64-72, 77-86, 91-99, 104-113` (`PromptProxyController.create`, `list`, `getActive`, `activate`, `deactivateActive`, `deleteVersion`)이 모든 요청에 `userId: req.session?.uuid`(관리자 JWT의 `String(user.id)`)를 주입하므로, 관리자가 `public-front/src/components/admin/PromptManagement.tsx:52-60, 79-96` (`handleActivate`, `handleCreate`)에서 프롬프트를 생성·활성화해도 전역 프롬프트(`userId=None`)가 아닌 관리자 개인 프롬프트로 저장되어 일반 사용자의 기본 프롬프트(`PromptService.get_active_prompt`, `public-python-server/src/ai_service/prompt/service.py:38-46`)에 반영되지 않는다. 반대로 일반 사용자의 `GET /ai/my-prompt/list`(`MyPromptProxyController.listMine`, `public-server/apps/gateway/src/ai/proxy/my-prompt-proxy.controller.ts:48-53`) 호출 시에는 `PromptTemplateRepository.find_all_by_name`(`repository.py:62-75`)이 `"$or": [{"userId": user_id}, {"userId": {"$exists": False}}]`로 전역 프롬프트까지 함께 반환하여, `public-front/src/components/ai/PromptSettingsModal.tsx:32, 234-328` (`PromptSettingsModal`)에서 전역 프롬프트가 개인 슬롯 한도(10개)를 차지하고 활성화·삭제 클릭 시 404 에러를 유발한다.
